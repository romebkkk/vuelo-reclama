# ✈️ Vuelo Reclama

> Calculate your EU261 flight compensation (250/400/600 €) for delays, cancellations or denied boarding, and generate the claim letter — without paying 25-35% to a claims agency.

**Free · open source · 100% in your browser (nothing is uploaded).**

<sub>[🇪🇸 Español abajo](#-español)</sub>

## Features
- Distance between 50 airports (great-circle)
- rerouting 50% rule
- extraordinary circumstances
- ready-to-send letter

## Use
Open `index.html` — no install, no server, no build. Host it free on GitHub Pages.

## Basis
Reglamento (CE) 261/2004; TJUE Sturgeon (C-402/07, C-432/07).

## ⚠️ Disclaimer
Orientative tool — not legal, tax or financial advice. Check your specific case with a professional.
